lang16-detector

Can a lightweight LSTM model accurately classify text across 16 different languages?

Try It

This demo runs a 6-layer LSTM model entirely in your browser via ONNX Runtime Web. No data leaves your device — the model, tokenizer, and vocabulary are all loaded locally.

Research Question

Can I build a efficent language identification model?

Methodology

The model is a 6-layer LSTM trained on character-level text. A WordPiece tokenizer (bert base multilingiual uncased) converts input text into token IDs, which are fed through the LSTM layers and a final classification head that outputs a probability distribution over 16 language classes.

01

Tokenization

Text is tokenized using a WordPiece vocabulary. Sequences are truncated or padded to a fixed length of 15 tokens.

02

LSTM Encoding

Token IDs are embedded and passed through 6 stacked LSTM layers(around 4M total parameters).

03

Classification

The final hidden state goes through a linear layer to produce a final probability distribution of the 16 classes.

Data

The model was trained on text samples across 16 languages. Each sample was tokenized with the WordPiece vocabulary and formatted as fixed-length sequences for the LSTM.

Experiments

The model was trained in PyTorch and exported to ONNX format for browser deployment. The exported model was then loaded into ONNX Runtime Web using the WebAssembly execution provider, allowing inference to run entirely in a static webpage

Results

The model achieves pretty good classification accuracy across the 16 languages while remaining lightweight enough to run in real time in a browser. The ONNX export preserves the exact behavior of the PyTorch model, and the WebAssembly backend delivers fast inference without requiring any server infrastructure.

16 Languages

Conclusion

This project demonstrates that a compact LSTM model can deliver accurate language identification across 16 languages. This shows that the same approach could be extended to more languages or adapted for other lightweight NLP tasks.
